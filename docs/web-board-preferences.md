# Патч 33 — рабочая веб-доска

Исправления поверх обложек 32/32а/32б. Android, Linux и OAuth остаются на паузе.

## Исправленная причина наезда

Селектор scoped-CSS обложки `:global(.board-task)>.task-cover` компилировался
Vue в `.board-task`: ширина +32px и отрицательные отступы применялись ко всей
карточке. Исправлен на `:global(.board-task > .task-cover)`. Регрессионный тест
компилирует настоящий scoped-CSS и проверяет конечную цель селектора.

Доска использует фиксированные колонки 300px (285px на узком экране), отступы 16px
и общий горизонтальный скролл. Заголовки остаются сверху, список карточек каждой
колонки прокручивается отдельно. Горизонтальный выход содержимого карточек ограничен.

## Поведение

- Первый вход без сохранённых настроек открывает доску всех задач.
- Обновление страницы всегда открывает вид «Доска», даже если перед этим выбрали
  «Список». В текущем сеансе список по-прежнему доступен кнопкой.
- Поиск, статус, проект, приоритет, активный рабочий раздел и выбранный проект
  бокового меню сохраняются отдельно для каждого аккаунта в localStorage браузера.
  Сохранённый рабочий раздел восстанавливается в виде доски.
- Архив/корзина не восстанавливаются как стартовый экран и не перезаписывают
  настройки активной доски. Выбор удалённого/архивного проекта сбрасывается после
  загрузки доступных проектов, чтобы не получать постоянно пустую доску.
- Настройки относятся к этому браузеру: синхронизация фильтров между устройствами
  не добавлена. Повреждённое или недоступное хранилище не блокирует работу.
- У карточек убраны стрелки порядка, селектор статуса и чек-кнопка завершения в
  списке. Ручное изменение статуса — через перетаскивание или форму деталки.
  Таймер и прежние правила автоматической смены статуса не меняются.
- Фильтры собраны в компактную подписанную панель; кнопка «Сбросить» очищает поиск
  и фильтры текущего раздела. Список/настройки столбцов находятся рядом.
- Техническая строка «Локальная версия / PostgreSQL» убрана из рабочего экрана.

## Проверки

Выполнены 22 frontend-теста и сборка Vue/TypeScript. Из них 7 новых тестов
настроек проверяют восстановление, изоляцию аккаунтов, повреждённые/неверные
значения, ограничение размера, отсутствующие проекты и сброс. Отдельный новый
тест проверяет реальный результат компиляции CSS обложки.

Изменений PHP/миграций БД нет. Визуальную приёмку выполнить в браузере после деплоя:
1. Открыть главную — показана доска; карточки не выходят за границы колонок.
2. Добавить картинку и проверить обложку в карточке и деталке.
3. Выбрать фильтры/поиск, обновить страницу — значения и рабочий раздел сохранены.
4. Переключиться в список, обновить страницу — снова доска с теми же фильтрами.
5. Перенести карточку между заполненными/пустыми колонками и внутри колонки.
6. Сменить статус в деталке, сохранить; проверить, что у карточки нет стрелок/селектора.
7. В другом аккаунте не должны показываться значения фильтров первого.
