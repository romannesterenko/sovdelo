# СовДело: описание проекта в JSON (патч 38)

В разделе «Импорт / экспорт» используется формат `sovdelo.transfer` с `schema_version: 2`.

У каждого элемента `projects` теперь поддерживается необязательное поле `description` (строка до 30 000 символов либо `null`).

Пример элемента массива `projects`:

```json
{
  "uuid": "9c1690ca-c25a-48a7-8c7b-b724ae6efdf1",
  "name": "СовЛавка",
  "description": "Цель: запустить сервис объявлений. Этапы: каталог, кабинет, модерация.",
  "archived_at": null
}
```

Полный документ должен содержать `format`, `schema_version`, `exported_at`, `columns`, `projects` и `tasks` в существующем формате экспорта. Самый надёжный способ создать файл — скачать JSON через «Импорт / экспорт» и заполнить поле `description` нужного проекта. При импорте можно включать задачи в `tasks`.

При стратегии «Пропустить существующие» новые проекты создаются с описанием; у существующего проекта с совпадающим UUID заполняется только пустое описание. Уже заполненные описания не заменяются. При стратегии «Создать отдельные копии» создаются новые проекты с описаниями. Повторная отправка того же запроса остаётся идемпотентной. Старые файлы без `description` продолжают приниматься.

Пароли, реквизиты доступа, обложки и файлы не импортируются.
