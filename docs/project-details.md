# Информация проекта (веб, этап 35)

В боковом меню выберите проект, затем нажмите «О проекте» над фильтрами. В окне три раздела:

- О проекте: название, описание до 30 000 символов, обложка.
- Файлы: загрузка, скачивание, удаление; до 50 файлов по 10 МБ. Лимит аккаунта 250 МБ общий с файлами задач, включая загрузки через API.
- Доступы: до 100 записей на проект; тип (сайт/сервер/другое), название, адрес (IP:порт либо URL), логин, пароль/ключ, примечание. Изменение и удаление доступны из записи. Пустое поле пароля при изменении сохраняет прежний пароль.

Первое изображение автоматически становится обложкой. Обложка отображается в окне проекта, рядом с названием доски и миниатюрой в меню. Можно выбрать другой файл или убрать обложку, сохранив файл. После ручного удаления обложки новые изображения не устанавливаются автоматически.

Несохранённое описание/доступ защищены подтверждением при закрытии и смене раздела. Каждая запись проверяет версию проекта: изменения из другой вкладки не перезаписываются молча. При конфликте скопируйте свой текст, закройте и откройте окно проекта заново.

## Данные и доступ

Текущая модель проектов — личная, по user_id. Все маршруты используют действующую веб-сессию и проверяют владельца проекта и принадлежность файла/записи. Совместный доступ этим патчем не включается. Архив доступен для чтения, изменение требует восстановления.

Файлы находятся на приватном диске local в project-files/<user_id>; прямых публичных ссылок нет. Просмотр изображений допускает JPEG/PNG/WebP/GIF, SVG и HTML не исполняются как обложки. Загружаемые документы выдаются как скачивание. Сам текст описания, названия и примечания выводятся без HTML.

Секрет зашифрован Laravel encrypted cast с APP_KEY, скрыт при сериализации и в общих списках; возвращается отдельным POST reveal по нажатию кнопки, ответ no-store. Раскрытое значение очищается из окна через 60 секунд, при смене вкладки браузера, раздела или закрытии окна. Оно не сохраняется в localStorage. Копирование выполняется только кнопкой пользователя; содержимое системного буфера остаётся до следующего копирования. Секреты следует помещать в поле «Пароль / ключ», описание и примечания шифрования не имеют.

Новые сведения, записи и файлы включаются в существующий полный серверный бэкап (PostgreSQL + storage/app + .env). Для восстановления зашифрованных секретов нужен исходный APP_KEY из .env; его нельзя заменять командой key:generate на действующем проекте. Обычный JSON-экспорт задач не содержит описание/обложку/файлы/доступы проекта и не заменяет полный бэкап. API устройств и помощников не получает новые разделы проекта.

## Проверка

Локально выполнить bash test.sh: отдельная тестовая база sovdelo_testing. Добавлены ProjectDetailsTest: сохранение и конфликт версий, шифрование и отсутствие секретов в списках/экспорте, изменение пароля, обложки, чужие файлы и проекты, гости, архив и общая квота web/API. Сборка проверяет TypeScript, npm run test:frontend — существующие frontend-регрессии.
