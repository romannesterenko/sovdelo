# СовДело — патч 02 (SD-004): Git и сборка

Применяется после патча 01. Распаковать в корень ~/Projects/sovdelo.

```bash
cd ~/Projects/sovdelo
unzip -o ~/Загрузки/sovdelo-patch-02-git-checks.zip -d .
bash scripts/git-init.sh
bash scripts/check.sh
```

git-init.sh создаёт отдельный локальный репозиторий только при его отсутствии и проверяет исключения. Существующие настройки автора, ветки, коммиты и remote не меняются. Если проект оказался внутри чужого репозитория, скрипт останавливается. Изменения автоматически не индексируются и не коммитятся.

После успешных проверок:

```bash
git add .
bash scripts/check-git.sh && git commit -m "СовДело: основа и проверки"
```

Если Git попросит автора, задайте свои имя и email локально через git config user.name / user.email. Скрипт не придумывает их автоматически.

Для GitHub создайте ПУСТОЙ приватный репозиторий sovdelo без README, .gitignore и лицензии. Затем можно подключить его:

```bash
git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
git push -u origin HEAD
```

Если origin уже есть — сначала проверьте `git remote -v`, не заменяйте его вслепую. Передайте URL в чат — продолжим с этим репозиторием. До git push исходники остаются только на вашем компьютере; внешнее резервирование ещё не настроено.

В .github/workflows/checks.yml добавлены проверки на push/pull_request: установка по lock-файлам, Vue/TypeScript, Laravel-тесты с изолированной PostgreSQL 17. Workflow скопирован по структуре СовПути с теми же закреплёнными версиями actions; серверный deploy отсутствует. CI заработает после отправки проекта в GitHub. Его успешный запуск пока не подтверждён.

Локально `bash scripts/check.sh` выполняет синтаксическую проверку shell, проверку имён отслеживаемых файлов Git, 12 Laravel-тестов из патча 01, npm ci и сборку. Python3 нужен для проверки Git. test.sh использует стандартный локальный порт 5433. Проверка имён не является полноценным поиском секретов внутри кода.

composer setup теперь вызывает тот же setup.sh --docker, не перегенерирует существующий APP_KEY. composer test использует защищённый test.sh. composer check — общую проверку.

Повторная чистая установка: клонировать проект в новую папку и выполнить bash setup.sh --docker. Не удаляйте .env и Docker volume действующего проекта. Отдельную установку с одновременной работой основной базы надо запускать со своими портами и Docker project name.

Откат патча до коммита: восстановить прежние composer.json/.gitignore из предыдущего коммита либо пакета основы, удалить только добавленные scripts и .github/workflows/checks.yml. Не удалять .git и .env. Патч не содержит миграций базы.

Проверено при подготовке: сборка Vue и bash-синтаксис; поведение git-init/check-git на временном репозитории. PHP/Docker отсутствуют, локальный Laravel-проход и GitHub Actions ожидают проверки пользователя.
