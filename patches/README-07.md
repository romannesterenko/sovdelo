```bash
cd ~/Projects/sovdelo
unzip -o ~/Загрузки/sovdelo-patch-07-archive-trash.zip -d .

bash test.sh
npm run build
```

Обновите страницу.

- В левом меню появились «Архив» и «Корзина». На телефоне они доступны через «Проекты».
- Задачу можно отправить в архив из карточки или в корзину вместо окончательного удаления.
- Из архива/корзины задача восстанавливается; сохраняются чек-листы, файлы, метки, комментарии, статус и проект. При восстановлении задача добавляется в конец своей колонки.
- В проекте доступна кнопка «В архив проект». Его задачи скрываются с активных представлений. Восстановление проекта возвращает его задачи, кроме отдельно архивированных или удалённых.
- Если задача восстановлена из корзины, а её проект ещё в архиве, она остаётся видна в архиве проекта. Сначала восстановите проект.
- Фильтр «Все статусы / Незавершённые / Завершённые» доступен над списком и доской.
- Вложения задач в корзине сохраняются на диске и учитываются в квоте. Через обычную ссылку задача/файлы из корзины недоступны до восстановления.
- Автоматическая очистка и безвозвратное удаление не включены: срок хранения пока не выбран. Архив и корзина не заменяют бэкапы.
- Удаление проектов пока не добавлено; доступно архивирование. Физически удалённые до этого патча задачи восстановить этим патчем нельзя.

В базе добавлены archived_at и deleted_at для задач, archived_at для проектов. Эти поля сохраняют факт архива/удаления для будущей синхронизации; сам протокол синхронизации пока не реализован.

Проверено: Vue/TypeScript build. Добавлены 6 Laravel-проверок, всего 31 в WorkspaceTest. PHP/Docker в среде подготовки отсутствуют; ожидается запуск у пользователя.

Ручная проверка:
1. Создать задачу с файлом, комментарием, меткой и чек-листом.
2. Отправить в корзину, обновить страницу, восстановить и проверить всё содержимое.
3. Архивировать/восстановить задачу.
4. Архивировать проект: он и задачи исчезают из активной доски. Восстановить проект из архива.
5. Проверить фильтр завершённых задач и изоляцию второго аккаунта.

После проверки сохранить в Git:

```bash
git add app routes database resources tests patches
bash scripts/check-git.sh && git commit -m "СовДело: архив и корзина с восстановлением"
git push
```

Откат: вернуть код предыдущего коммита и собрать Vue. Таблицы/колонки не удалять: они содержат данные об архиве/корзине. Старый код не учитывает deleted_at и может показать удалённые задачи, поэтому откат требует проверки на отдельном окружении.
