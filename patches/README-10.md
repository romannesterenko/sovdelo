# Патч 10 — повторяющиеся задачи (SD-011)

Применять после 09. Ежедневные, еженедельные, ежемесячные серии.

## Установка

```bash
cd ~/Projects/sovdelo &&
unzip -o ~/Загрузки/sovdelo-patch-10-recurring-tasks.zip -d . &&
php artisan migrate &&
bash test.sh &&
npm run test:frontend &&
npm run build &&
git add app routes database resources tests patches &&
bash scripts/check-git.sh &&
git commit -m "СовДело: повторяющиеся задачи" &&
git push
```

## Как пользоваться

Сохранить задачу, открыть её детали, нажать «Повторяющиеся задачи», затем «Создать серию». Выбрать частоту и первую дату. Исходная задача остаётся самостоятельной: серия создаёт новые экземпляры, в том числе при выборе сегодняшней даты. Для первого нового экземпляра завтра выбрать завтрашнюю дату.

В шаблон копируются сохранённые название, описание, проект, приоритет, метки и чек-лист. Каждый новый чек-лист сброшен. Файлы, комментарии, время, крайний срок не копируются. Плановая дата экземпляра — дата повтора. Шаблон независим от исходной задачи.

Через то же окно можно изменить название, описание, приоритет, частоту и следующую дату будущих задач; остановить или продолжить серию. Изменение конкретной задачи не меняет шаблон, редактирование шаблона не меняет созданные задачи. Чтобы изменить проект, метки или состав чек-листа шаблона, приостановить старую серию и создать новую из нужной задачи.

Расписание привязано к календарным датам в часовом поясе аккаунта. Неделя — каждые 7 дней от выбранной даты. Месячная серия сохраняет число: 31 января → 28/29 февраля → 31 марта. Раннее завершение экземпляра не сдвигает даты. Пропущенные повторы сворачиваются в один последний наступивший экземпляр; незавершённые старые задачи сохраняются. Каждая серия имеет свою дату следующего запуска.

Архив проекта блокирует генерацию до восстановления; затем применяется то же правило пропусков. Архив и корзина экземпляра не останавливают серию. Удалённый экземпляр не создаётся повторно за ту же дату. Для остановки будущих задач приостановить саму серию.

## Локальная генерация

Повторы проверяются при загрузке / обновлении списка задач. Для фоновой генерации открыть второй терминал:

```bash
cd ~/Projects/sovdelo
php artisan schedule:work
```

Либо разово `php artisan sovdelo:recurring`. Фоновая генерация не отправляет push и не обновляет автоматически уже открытую вкладку: обновить страницу для отображения новых задач. Серверный cron настроим при размещении на сервере.

Генерация и изменение шаблонов используют общую блокировку пользователя; уникальный индекс серии/даты и ключ запроса защищают от дублей. Шаблоны и задачи изолированы по аккаунтам.

## Проверки

Добавлены 8 backend-тестов: независимость экземпляра и сброс чек-листа/метки; пропуски и часовой пояс; короткий месяц/високосный год; пауза и правка будущих; изоляция/валидация; архив проекта; повтор POST; корзина. Всего 51 тест WorkspaceTest. Здесь PHP/Docker недоступны: серверные тесты запускаются командой установки. TypeScript/Vite и существующие 8 frontend-тестов проверены при подготовке.

Ручная проверка: серия на сегодня создаёт отдельную задачу; обновление страницы и повтор команды не дублируют её; правка экземпляра не меняет шаблон; пауза прекращает генерацию; аккаунт другого пользователя не видит серию.

## Откат

Сначала сохранить необходимые данные новых экземпляров. Откат миграции удаляет шаблоны и связь с сериями, но оставляет созданные задачи. Откатывать код и последнюю миграцию согласованно; после появления следующих миграций не выполнять rollback вслепую.
