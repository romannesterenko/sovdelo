# СовДело — патч 05: канбан и сохранение порядка (SD-007)

Применяется после 01/02/04. Патч 03 не требуется.

```bash
cd ~/Projects/sovdelo
unzip -o ~/Загрузки/sovdelo-patch-05-kanban-order.zip -d .
php artisan migrate
bash test.sh
npm run build
```

Обновите страницу, откройте проект и включите «Доска».

Добавлено:
- Перенос между тремя статусами, вставка до/после карточки и в пустую колонку.
- Видимый блок места вставки.
- Кнопки ↑/↓ и выбор статуса на карточке для телефона и клавиатуры.
- Серверное sort_order, сохранение после перезагрузки; существующие задачи получают исходный порядок по ID.
- Новые задачи и задачи, переведённые через редактор в другой статус, добавляются в конец колонки.
- Транзакции и блокировка аккаунта на изменение порядка, создание, редактирование и удаление; чужие задачи и чужие места вставки недоступны.
- При ошибке серверного запроса доска остаётся в прежнем состоянии. Если ответ потерялся после успешной записи на сервере, обновите доску — она покажет фактически сохранённый порядок.
- Изменения карточки перед переносом нужно сохранить/закрыть. Перетаскивание при несохранённых изменениях отключено; альтернативные кнопки используют диалог подтверждения.

Порядок общий для аккаунта внутри каждого статуса; фильтр проекта/даты/поиска показывает его подмножество. При переносе относительный порядок остальных, в том числе скрытых фильтром, карточек сохраняется. Перенос не меняет проект задачи. Устаревшее место вставки отклоняется сервером с ошибкой, а не подменяется молча.

Проверки:
- Vue/TypeScript production build выполнен в среде подготовки.
- Добавлены 7 серверных сценариев к существующему WorkspaceTest; bash test.sh теперь должен выполнить 19 тестов. PHP/Docker здесь отсутствуют, прохождение серверных тестов не подтверждено.
- Ручная проверка на реальном Laravel и touch-устройстве остаётся за пользователем.

Проверить вручную:
1. Создать 3–4 задачи, переставить последнюю между первой и второй, обновить страницу.
2. Перенести в пустую «В работе», затем в «Готово», обновить страницу.
3. Проверить стрелки и выбор статуса без перетаскивания.
4. Отфильтровать задачи поиском и переместить видимую карточку; после очистки поиска остальные сохраняют взаимный порядок.
5. Проверить ошибку сети: до обновления интерфейс не должен показывать несохранённый перенос как успешный.
6. Проверить две вкладки: если место вставки уже ушло в другую колонку, перенос должен быть отклонён.
