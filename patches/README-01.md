# СовДело — патч 01: проверка основы (SD-003)

Применяется к sovdelo-0.1-local-foundation.zip, в корень ~/Projects/sovdelo.

Изменения:
- Создание задачи возвращает свежую запись из PostgreSQL вместе с дефолтными status/priority, чтобы карточка сразу отображалась на доске.
- Проверка содержимого пунктов чек-листа: разрешены только text/done.
- Нормализация email при входе и ограничения длины полей.
- Явное приведение внешних ключей задачи к integer для проверки владельца.
- 12 проверок: регистрация/вход, неправильный пароль, дубликат email, гостевой доступ, изоляция аккаунтов, попытка подмены владельца/проекта, валидация и полный цикл задачи.
- test.sh использует отдельный compose-проект sovdelo и отдельную базу sovdelo_testing. Тестовый TestCase останавливает запуск до миграций, если выбрана другая база, другой драйвер, не testing или задан DB_URL.

Установка и проверка:

```bash
cd ~/Projects/sovdelo
unzip -o ~/Загрузки/sovdelo-patch-01-foundation-checks.zip -d .
bash test.sh
npm run build
```

Команды миграции рабочей базы для этого патча не нужны. Тесты выполняют миграции в отдельной sovdelo_testing. Нужна работающая PostgreSQL из bash setup.sh --docker, на стандартном порте проекта 5433. Не подменяйте переменные подключения на рабочую базу. При нестандартном порте передайте его в отдельной правке test.sh после проверки окружения.

В среде подготовки выполнены сборка Vue с проверкой TypeScript, проверка синтаксиса bash и инспекция кода. PHP и Docker здесь отсутствуют, поэтому прохождение PHP-тестов НЕ подтверждено; ожидается результат с Ubuntu пользователя.

Ручная проверка после тестов:
1. В обычном окне войдите в аккаунт А; создайте проект, задачу, чек-лист, сохраните и обновите страницу.
2. В приватном окне создайте аккаунт Б: проекты и задачи А не должны отображаться.
3. Создайте новую задачу в проекте и переключите на «Доска» — она должна сразу быть в «К выполнению».
4. Переключите статус, завершите и верните задачу; сохранение проверяется перезагрузкой.
5. Проверьте неверный пароль и выход, затем страницу на телефоне или узком окне.

Не отмечать SD-003 завершённой до результата тестов и ручной проверки.
