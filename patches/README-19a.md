# Патч 19a — информационные замечания Flutter 3.50

Bootstrap запускает `flutter analyze --no-fatal-infos`. Информационные замечания
об устаревающих API выводятся, но не блокируют следующий шаг. Ошибки и предупреждения
остаются блокирующими. Исходники созданного app/ не перезаписываются.

Причина: на Flutter 3.50 импорт flutter/material.dart отмечен deprecated.
Миграция UI на новый пакет требует отдельной проверки совместимости и этим патчем
не выполняется. После анализа скрипт продолжает запуск теста SQLite.

Проверено: синтаксис Bash и состав ZIP. Flutter здесь не установлен;
анализ, тест и запуск приложения выполняются локально разработчиком.
