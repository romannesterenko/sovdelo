# Этап 34 — интерфейс в пределах окна и оформление

После этапа 33. Распаковать в корень проекта, выполнить npm run test:frontend и npm run build, затем закоммитить и отправить изменения. Миграций нет.

Доска занимает оставшуюся высоту окна. Каждая колонка, список задач, архив и навигация имеют собственную прокрутку. Подвал и активный таймер занимают место в потоке, не перекрывая карточки. На узком экране навигация находится под подвалом; при малой высоте верхняя панель также прокручивается. Полосы прокрутки соответствуют теме.

Единый логотип в авторизации и боковой панели, SVG-иконки, favicon SVG/ICO/PNG, иконки Android/iOS и manifest. После обновления обновить страницу Ctrl+Shift+R; закреплённую иконку браузер может обновить позже.

Проверка вручную: доска с заполненными и пустыми колонками; горизонтальная прокрутка; длинный список проектов; режим списка; архив; таймер; светлая тема; уменьшенная высота окна; мобильный экран; модальные окна. Подвал остаётся видимым, карточки и списки прокручиваются внутри. Авторизация и большие диалоги сохраняют прокрутку.

Автоматически проверены TypeScript, production-сборка и frontend-тесты. Визуальная проверка в браузере в среде подготовки недоступна.
