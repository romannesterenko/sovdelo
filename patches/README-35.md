# Этап 35 — информация проекта, файлы, обложка и доступы

Требуется этап 34. Распаковать ZIP в корень проекта. Запустить локальный PostgreSQL, php artisan migrate, bash test.sh, npm run test:frontend и npm run build. Закоммитить изменения и отправить в main — GitHub Actions применит миграцию при деплое.

Открыть проект слева → «О проекте» над фильтрами. Добавить описание, во вкладке «Файлы» загрузить изображение и документ; проверить выбор и снятие обложки. Во вкладке «Доступы» создать сайт/сервер, сохранить и повторно открыть окно; проверить показ/скрытие пароля. Открыть тот же проект в двух вкладках и убедиться, что старая вкладка не перезаписывает новые изменения.

Новые данные входят в существующие полные бэкапы. Не менять APP_KEY: он нужен для расшифровки сохранённых паролей. Обычный JSON-экспорт задач не включает новые разделы проекта. Подробности: docs/project-details.md.

При подготовке прошли сборка TypeScript/Vue и 22 frontend-теста. PHP и PostgreSQL в среде подготовки отсутствуют, поэтому новые Laravel-тесты нужно выполнить локально до коммита; визуальная проверка браузера также выполняется после установки.

test.sh и GitHub Actions запускают весь набор Laravel-тестов, чтобы включать новые проверки проекта.
