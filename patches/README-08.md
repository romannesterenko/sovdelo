Две даты:
- «Запланировано на» — когда заниматься задачей; влияет на списки по дням.
- «Крайний срок» — дедлайн; перенос плана не меняет этот срок.

Миграция существующим задачам копирует прежний due_date в planned_date, сохраняя и сам due_date. Прежняя дата трактуется как срок И план, чтобы старые задачи не исчезли из расписания. Новые задачи могут иметь только план, только срок, обе даты или ни одной.

«Сегодня»: незавершённые задачи, у которых план или срок наступили/прошли; просроченный дедлайн подсвечивается и стоит первым в списке. Задачи с прошедшей плановой датой остаются в Сегодня до переноса или завершения. Выполненные задачи прошлых дней не возвращаются в просрочку. У завершённых задач в Сегодня остаются только задачи с планом на сегодняшний день (или сроком на сегодня при отсутствии плана).

«Предстоящие»: незавершённые задачи с будущим планом (или будущим сроком без плана) без просроченного дедлайна. В списке сортируются по этой дате; канбан сохраняет ручной порядок. Задачи без дат находятся во Входящих/Все задачи/проекте.

Быстрые действия: «На завтра» в списке сохраняет только плановую дату сразу. В редакторе «Сегодня», «Завтра», «Без даты» изменяют план; затем нажать «Сохранить изменения» или Ctrl+S. Произвольную дату выбрать в поле. Просроченный дедлайн при переносе плана на завтра остаётся просроченным и задача остаётся в Сегодня — срок не скрывается.

Фильтры: проект, приоритет, статус, поиск. При переходе в другой раздел фильтры проекта/приоритета сбрасываются; ручной порядок карточек сохраняется.

Часовой пояс: кнопка ◷ в верхней панели. По умолчанию Europe/Moscow; настройка хранится в аккаунте. День вычисляется в выбранном поясе, не в поясе браузера; экран обновляет текущий день примерно раз в 30 секунд без запросов к серверу. Время на устройстве должно быть корректным. В интерфейсе доступны российские пояса и UTC; API принимает валидные IANA-зоны. Напоминания будут отдельным этапом.
