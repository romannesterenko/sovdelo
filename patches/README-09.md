# СовДело — патч 09: таймер и история времени (SD-010)

После 08/08a. Отложенный 03 не требуется.

```bash
cd ~/Projects/sovdelo
unzip -o ~/Загрузки/sovdelo-patch-09-task-timer.zip -d .
php artisan migrate
bash test.sh
npm run test:frontend
npm run build
```

Обновите страницу и откройте задачу. Над списком появится блок «Время задачи»: начать/приостановить/история. При запущенном или приостановленном таймере постоянная панель доступна снизу на компьютере и телефоне. Перед управлением сохраните изменения карточки.

- Один активный таймер на аккаунт: блокировка строки пользователя в транзакции и UNIQUE partial index PostgreSQL по незавершённой сессии.
- Старт новой задачи останавливает предыдущую. Задача «К выполнению» автоматически переходит «В работе» в конец колонки.
- Пауза закрывает и сохраняет сессию; продолжение создаёт следующую. Кнопка ■ завершает отсчёт, не завершает саму задачу.
- Завершение задачи, её архив/корзина или архив проекта останавливают таймер.
- Перезагрузка/выход из аккаунта/закрытие вкладки НЕ останавливают таймер: он хранится на сервере и продолжает учитывать время. Если нужно остановиться — нажмите паузу/■.
- Отсчёт берётся с сервера, между ответами отображается по performance.now(). При возвращении в окно/появлении сети сверяется сразу; во время видимой вкладки проверяется примерно раз в 20 секунд.
- Действия требуют сети. При отсутствии связи показывается предупреждение; последняя цифра не означает подтверждённую офлайн-запись. Полноценный офлайн-таймер/синхронизация будут на этапе приложений.
- Команда старта содержит UUID: повторы не создают дубликатов и не переключают назад на старую задачу. Остановка адресуется конкретной сессии: запоздалый запрос не остановит новую сессию.

История: последние 30 сессий выбранной задачи, итог по всей истории. Время показывается в часовом поясе аккаунта. «Исправить» доступно только завершённой сессии: длительность в секундах (0–604800) и причина (3–500 символов). Кнопка явно подтверждает корректировку; записываются старое/новое значение и причина. Корректировка не меняет реальные временные метки начала/конца. История сохраняется при архивировании и попадании задачи в корзину.

Проверено в среде подготовки: Vue/TypeScript build и 8 существующих Node-тестов. 9 новых Laravel-тестов (всего 43) подготовлены, но PHP/Docker здесь отсутствуют. PostgreSQL partial index используется намеренно: проект рассчитан на PostgreSQL, не SQLite.

Ручная проверка:
1. Запустить A, подождать, обновить страницу — отсчёт сохраняется.
2. Запустить B — A остановлена, B одна активная.
3. Пауза/продолжение/■; проверить сумму в истории.
4. Во второй вкладке запустить другую задачу и вернуться в первую — состояние сверится с сервером.
5. Завершить/архивировать/отправить в корзину работающую задачу — таймер остановится.
6. Исправить длительность завершённой сессии, указать причину; проверить итог и историю корректировок.
