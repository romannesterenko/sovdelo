# Патч 19 — SD-017: проверка Flutter на Ubuntu и Android

Добавлены отдельный локальный прототип, bootstrap, тест повторного открытия SQLite,
инструкция окружения и ADR с альтернативой Tauri. Сайт и API не изменяются.

В этой среде выполнены проверка Bash, проверки конфигуратора Android на шаблоне
и отказа на неизвестном шаблоне. Flutter SDK здесь отсутствует: pub get, Dart analysis,
Flutter test и сборки Linux/Android НЕ выполнены. Bootstrap запускает их на машине разработчика.
Системные уведомления и защищённое хранилище подтверждаются вручную на устройствах.
SD-017 остаётся открытой до приёмки Linux и Android.

Установка: распаковать ZIP в корень ~/Projects/sovdelo, затем следовать
clients/flutter-probe/README.md. Не запускать этот прототип на сервере.
