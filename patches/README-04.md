# СовДело — патч 04: карточка задачи и сохранение (SD-006)

Применяется после 01 и 02. Патч 03 резервного копирования не нужен и остаётся отложенным.

```bash
cd ~/Projects/sovdelo
unzip -o ~/Загрузки/sovdelo-patch-04-task-editor.zip -d .
npm run build
```

Обновить страницу. Изменения только во Vue/CSS; миграции базы и установка новых зависимостей не нужны.

Что изменилось:
- Статус «Есть несохранённые изменения» и подтверждение при закрытии карточки, выборе другой задачи, переходе в раздел, создании новой задачи/проекта или выходе.
- Нажатие на текущую карточку не сбрасывает её редактор.
- Ctrl+S / Cmd+S сохраняет карточку; Escape закрывает её через проверку несохранённых данных.
- Введённый, но ещё не добавленный пункт чек-листа учитывается как изменение и добавляется при сохранении.
- Во время сохранения поля и повторные отправки заблокированы; ошибки показываются также внутри карточки и не очищают черновик.
- Удаление подтверждается диалогом в стиле сайта. Фокус в диалоге, переключение Tab/Shift+Tab и возврат к полю по отмене.
- SVG-иконки навигации, чек-листа и приоритета в одном стиле.
- При обновлении/закрытии вкладки браузер показывает собственное предупреждение о несохранённых данных (его оформление задаёт браузер). Это не офлайн-черновик: после подтверждённого ухода введённое теряется.

Ручная приёмка:
1. Открыть задачу, изменить описание, нажать на другую: выбрать «Остаться», убедиться, что текст сохранён в форме.
2. Повторить и выбрать «Не сохранять и продолжить»: открывается другая задача.
3. Добавить/отметить пункт чек-листа, сохранить Ctrl+S, обновить страницу — изменения на сервере.
4. Ввести пункт без нажатия «+» и сохранить — пункт должен добавиться.
5. При выключенной сети попробовать сохранить: ошибка видна внутри карточки, текст не исчезает. Подключить сеть и повторить сохранение.
6. Проверить удаление и отмену в новом диалоге, Escape, Tab и узкий экран телефона.
7. Изменить текст и попробовать перезагрузить страницу: браузер предупреждает.

Сборка Vue с vue-tsc проверена в среде подготовки; работа с реальным Laravel и ручные сценарии ожидают проверки на Ubuntu пользователя.

Сохранить после проверки:

```bash
git add resources/js/App.vue resources/js/Icon.vue resources/css/app.css patches/README-04.md
git commit -m "СовДело: сохранение и защита изменений карточки"
git push
```

Откат: вернуть эти файлы из предыдущего коммита, удалить Icon.vue, если он не существовал, и выполнить npm run build. Данные базы патч не меняет.
