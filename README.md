# СовДело 0.1 — локальный Laravel

Основа повторяет СовПуть из предоставленного архива: Laravel ^13.17, PHP ^8.3, Vue 3 + TypeScript, Vite 7, PostgreSQL 17 в Docker. PHP/Composer/Node запускаются на Ubuntu. В зависимостях сохранены версии и lock-файлы СовПути, включая Filament и Sanctum; отдельная админ-панель пока не настроена.

## Установка

Распакуйте архив в НОВУЮ папку `~/Projects/sovdelo` (не в СовПуть).

```bash
cd ~/Projects/sovdelo
bash setup.sh --docker
composer run dev
```

Сайт: http://localhost:8010. Vite: 5174. PostgreSQL: 5433.
Создайте свой аккаунт через «Зарегистрироваться». Демо-паролей и готовых аккаунтов нет.

`setup.sh` проверяет зависимости, создаёт .env со случайным паролем базы, устанавливает пакеты, генерирует APP_KEY только при его отсутствии, запускает контейнер PostgreSQL, применяет миграции и собирает Vue. Повторный запуск не меняет существующие .env/APP_KEY. Нужны те же зависимости Ubuntu, что и для СовПути. Команды не меняют файлы, базы или контейнеры СовПути.

Docker используется только для отдельной базы, как в СовПути. Имя compose-проекта — sovdelo; отдельный volume — sovdelo_pg. `docker compose down` останавливает базу. Не используйте `down -v`: это удаляет её данные.

## Что работает

Регистрация, вход, выход; отдельные данные каждого аккаунта; создание проектов; создание, редактирование и удаление задач; сроки и приоритеты; чек-листы; представления «Сегодня», «Входящие», «Предстоящие», «Все задачи» и проект; поиск; список и доска по статусам; светлая/тёмная тема; адаптация к телефону.

После редактирования карточки нажмите «Сохранить изменения», в том числе для чек-листа. Переключение завершения задачи в списке сохраняется сразу.

Данные хранятся в PostgreSQL на компьютере, а не в localStorage. Другие аккаунты их не видят. Сайт требует соединения с Laravel. Полноценная офлайн-синхронизация, таймер, Android/Linux-приложения, перетаскивание на доске, восстановление пароля и подтверждение email будут следующими этапами. Данные из прежнего браузерного прототипа автоматически не переносятся.

## Проверки

Фронтенд проверен: `npm ci`, `npm run build` (включает vue-tsc).
PHP/Composer в среде подготовки отсутствовали: миграции, запуск Laravel и тесты здесь не выполнялись.

Для проверок на вашем Ubuntu при запущенной базе:

```bash
bash test.sh
```

Скрипт создаёт отдельную базу sovdelo_testing внутри контейнера СовДела и запускает четыре проверки: регистрация/вход, закрытость для гостей, изоляция аккаунтов и сохранение задачи с чек-листом. Не запускайте тесты на production. `RefreshDatabase` очищает только выбранную тестовую базу. Перед тестами скрипт очищает кеш конфигурации.

## Изменения и сервер

Дальнейшие ZIP-патчи распаковываются в корень ЭТОГО проекта. Храните исходники в отдельном Git-репозитории. .env, vendor, node_modules, storage и резервные копии не коммитить.

На сервер переносятся этот проект, его отдельная PostgreSQL-база и собранный public/build. Document root Nginx должен указывать в public, APP_ENV=production, APP_DEBUG=false, HTTPS, SESSION_SECURE_COOKIE=true. Серверный .env создаётся отдельно; composer install --no-dev --optimize-autoloader, php artisan migrate --force, php artisan optimize. Схему конкретного развёртывания и автоматических резервных копий настроим отдельным этапом; текущий setup.sh предназначен для локальной Ubuntu, не для production.

## Резервные копии

До настройки автоматики можно делать копию вручную (из корня проекта):

```bash
mkdir -p backups
docker compose exec -T postgres sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc' > "backups/sovdelo-$(date +%Y%m%d-%H%M%S).dump"
```

Храните копии также вне компьютера/основного сервера. Сам по себе Docker volume резервной копией не является.
